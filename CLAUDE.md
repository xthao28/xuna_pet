# Claude Code instructions

Read and follow [AGENTS.md](AGENTS.md) before proposing changes or writing code. It is the canonical project guide. Follow additional submodule instructions when present, and respect independent Git repositories. Before writing or changing code in `mobile/`, read [mobile/AGENTS.md](mobile/AGENTS.md) (mobile coding rules) and, for new features, [mobile/docs/FEATURE_TEMPLATE.md](mobile/docs/FEATURE_TEMPLATE.md). Before writing or changing code in `backend/`, read [backend/AGENTS.md](backend/AGENTS.md) and [backend/docs/ARCHITECTURE.md](backend/docs/ARCHITECTURE.md), and run `backend/scripts/check.sh`.

Then read [PROCESS.md](PROCESS.md) for the current milestone, session handoff and next actions. Read [PLAN.md](PLAN.md) for tasks and the latest [CHANGELOG.md](CHANGELOG.md) entries for recent changes. Verify repository state and update the relevant handoff documents after meaningful work.
