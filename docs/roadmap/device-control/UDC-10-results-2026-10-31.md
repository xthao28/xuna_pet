## 2. Product & Security Invariants Enforced

1. **Honest rule labelling (AGENTS.md §6):**
   - 3-pick host-default suggestions are explicitly labelled `"Gợi ý theo quy tắc"`.
   - Routine action suggestions are explicitly labelled `"Gợi ý theo thói quen"`.
   - Neither is ever described as "AI learning", and the `"Tại sao?"` ("Why?") view displays the exact rule and counts (`3/4 tuần gần đây`, total count, and Routine V1 presence).
2. **Owner confirmation & tie-breaker only (`S10.1`):**
   - `host_default` conventions exist only after owner confirmation (either confirming the 3-pick rule card or confirming a chat candidate).
   - `TargetResolver` uses `host_default` only as a tie-breaker when no explicit host alias is given, multiple hosts are eligible, and `last_target_5m` does not apply.
   - `host_default` never skips an `R2` or `R3` approval (`requiresApproval == true`).
   - Deleting a `host_default` convention takes effect immediately on the very next targeting decision.
3. **Zero auto-execution & phone-local content-free history (`S10.2`):**
   - Routine offers have `autoExecute == false` and require an explicit owner tap (`"Thực hiện"`), which runs through normal policy and grants.
   - Phone-local action history (`RoutineHistoryBucket`) records only `(family, hostAlias, hourOfWeek, weekIndex, count)` for `R0`/`R1` actions — never URLs, file paths, window titles, or query strings.
   - Declining or ignoring an offer twice in a row pauses that offer key for 14 days (`2 weeks`).
4. **Bond level & personality boundaries (`S10.3`):**
   - Bond level (`KnowledgeLevel`) caps daily offer count only (`0 / 1 / 2 / 3`) and **never** changes grants, risk tiers, or approvals (proven exhaustively across all `(bondLevel, risk, maxGrantRisk, familyEnabled, hasHostDefault)` combinations in both Python and Dart unit tests).
   - Personality (`PersonalityLabel`) changes offer wording only, never daily caps or execution.
