## 1. Summary of Delivered Slices (`S13.1` → `S13.5`)

1. **`S13.1` — Instant Active-Window Context (`window.active_context`, `R1`, `ToolFamily.app`, `observes: true`):**
   - `desktop/packages/xuna_xtp`: Added `window.active_context` tool descriptor (`maxChars: 100..1200`), hard-denylist check (`isHardDeniedAppOrProcess`), and automatic secret redaction (`redactSensitiveSelectionText`).
   - `desktop/`: Implemented native foreground window inspection in `xuna_host_plugin.cpp` (`GetForegroundWindow` + `IUIAutomation` focused control + elevation check) and `XunaHostPlugin.swift` (`NSWorkspace.shared.frontmostApplication` + `AXUIElementCopyAttributeValue`), plus `HostToolDispatcher._handleWindowActiveContext` (`elevated_window_forbidden` / `denylisted_target_forbidden` refusal, secret redaction, content-free audit logging).
   - `backend/`: Added `window.active_context` to `ActionCatalog` (`R1`, `HostGrantFamily.APP`, `observes=True`) and `WorkflowTemplate.ACTIVE_WINDOW_SUMMARY` (`active_window_summary`).

2. **`S13.2` — Semantic Browser Co-Pilot (`browser.read_page`, `R1`, `ToolFamily.url`, `observes: true`) & `@playwright/mcp` Detection:**
   - `desktop/packages/xuna_xtp`: Added `browser.read_page` tool descriptor (`browser: "auto"|"edge"|"chrome"|"safari"`, `maxChars: 100..1600`) and enforced `isAllowedHttpsCurrentUrl` (`https://` only, no loopback/private IPs) + `redactSensitiveSelectionText`.
   - `desktop/`: Implemented `browserReadPage` on Windows (`IUIAutomation`) and macOS (`NSAppleScript` DOM title/headings/interactive actions/excerpt extraction), extended `AutoMcpBridge.hasPlaywrightMcp` to detect `@playwright/mcp` (`playwright`), and dispatched `browser.read_page` with zero URL/content logging.
   - `backend/`: Added `browser.read_page` to `ActionCatalog` (`R1`, `HostGrantFamily.URL`, `observes=True`) and `WorkflowTemplate.BROWSER_SUMMARY` (`browser_summary`).

3. **`S13.3` — XUNA Beam (`beam.transfer`, `R2`, `ToolFamily.app`, Peer-to-Peer LAN Transfer):**
   - `desktop/packages/xuna_xtp`: Added `beam.transfer` tool descriptor, `isValidBeamFileName` (rejects path traversal `..`, `/`, `\`, hidden dotfiles, and executable extensions `.exe`, `.bat`, `.cmd`, `.ps1`, `.sh`, `.command`, `.app`, `.dmg`, `.pkg`, `.msi`, `.apk`, `.ipa`, `.dll`, `.so`, `.dylib`), and `sha256Hex`.
   - `desktop/`: Implemented `HostToolDispatcher._handleBeamTransfer` verifying payload size (`<= 25 MiB`), filename safety, and SHA-256 digest before writing into `XUNA_Beam/`. Zero file bytes pass through `backend/`.
   - `mobile/`: Added `BeamTransferTicket` (`BeamTransferTicket.fromBytes`, `BeamTransferTicket.isValidBeamFileName`, `toToolArguments`) and `HomeActionsService.prepareBeamTransfer` / `lastBeamTicket`.

4. **`S13.4` — Atomic Batch Execution (`workflow.batch_steps`, `R2`, `ToolFamily.workflow`):**
   - `desktop/packages/xuna_xtp`: Added `workflow.batch_steps` (`1..5` steps) to `HostPolicyEvaluator.evaluate` with **validate-all-before-run** semantics: every step is validated against `HostPolicyEvaluator` before Step 1 executes, and any `R3`/forbidden/unlisted step rejects the entire batch up front.
   - `desktop/`: Implemented `HostToolDispatcher._handleWorkflowBatchSteps` pre-validating all steps before executing Step 1 and halting on first step failure.
   - `backend/`: Implemented `WorkflowPlanRunner._run_batch_steps` (`WorkflowTemplate.BATCH_STEPS`) pre-validating every step against `ActionCatalog` and `is_tool_granted` before requesting a single `R2` approval and dispatching `workflow.batch_steps`.

5. **`S13.5` — Reversible Action Ledger & Quick Undo (`action.undo`, `R1`, `ToolFamily.app`):**
   - `desktop/`: Added bounded 5-entry in-memory `ReversibleActionLedger` (10-minute TTL) recording `media.play_pause`, `media.volume_set` (with previous volume), and `host.lock_screen` (`display.wake` inverse), and implemented `action.undo` (`R1`) to pop and execute the inverse operation.
   - `backend/` & `mobile/`: Added `action.undo` (`R1`) and `WorkflowTemplate.QUICK_UNDO` (`quick_undo`), `BoardWorkflowSlotConfig.ambientCopilotPresets`, and `HomeActionsService.markReversibleActionCompleted` / `consumeUndoAction`.
