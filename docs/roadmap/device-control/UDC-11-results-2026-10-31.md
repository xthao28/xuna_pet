### `S11.2` — Zero-Config App & Project Auto-Discovery (`AutoAppScanner` + `AutoWorkspaceIndexer` + `workspace.open` + `workspace.git_summary`)
- **`AutoAppScanner` (`desktop/lib/features/discovery/auto_app_scanner.dart`):**
  - Automatically scans installed macOS (`/Applications`, `~/Applications`) and Windows (Start Menu `.lnk`, `Program Files`, `%LOCALAPPDATA%\Programs`) applications plus developer CLIs (`claude`, `agy`, `cursor`, `code`, `codex`) without manual user configuration.
  - Strictly enforces hard-denied executable rules (`cmd`, `powershell`, `pwsh`, `wt`, `bash`, `sh`, `zsh`, `terminal`, `iterm`, `regedit`, `taskmgr`, `keychain`, `1password`, `bitwarden`).
  - Integrated into `AppLaunchTool` (`desktop/lib/features/tools/host_tool_dispatcher.dart`) as a zero-config fallback when an application ID is not in the static allowlist.
- **`AutoWorkspaceIndexer` (`desktop/lib/features/discovery/auto_workspace_indexer.dart`):**
  - Automatically indexes developer projects from:
    1. Claude Code history (`~/.claude.json` `projects` keys),
    2. Antigravity / Cursor / VS Code recent workspaces (`globalStorage/storage.json`), and
    3. Shallow Git repository scan (depth ≤ 3 under `~/Documents`, `~/Projects`, `~/Developer`, `~/Repos`, `~/Desktop`, `~/work`).
  - Supports fuzzy matching by alias/token (`resolveWorkspace("xuna")` → `xuna_pet`) while keeping raw filesystem paths strictly local to the desktop host.
- **`workspace.open` (`R2`) & `workspace.git_summary` (`R1`):**
  - Added tool schemas and policy rules in `xuna_xtp`, `desktop/`, and `backend/`.
  - `WorkspaceOpenTool` opens the resolved project in `antigravity`, `cursor`, or `vscode` (`runInShell: false`).
  - `WorkspaceGitSummaryTool` runs read-only `git -C <path> status --porcelain=v1 -b` (`runInShell: false`, 3 s timeout) and returns `{workspace, branch, clean, modifiedCount, untrackedCount}` with zero raw filesystem paths or file contents.

### `S11.3` — `workspace.coding_agent` & `resume_work` / `wrap_up_work` Composite Workflows
- **`workspace.coding_agent` (`R2`, `ToolFamily.app`):**
  - Added `WorkspaceCodingAgentTool` in `desktop/lib/features/tools/host_tool_dispatcher.dart`.
  - Resolves the project via `AutoWorkspaceIndexer`, discovers the requested coding agent (`claude_code`, `antigravity`, `cursor`, `vscode`, `codex`, or `auto` priority), and launches it with `runInShell: false` (`--continue` + synthesized continuation prompt for `claude_code` / `codex`; workspace path + `--reuse-window` for IDEs).
  - Never passes `--dangerously-skip-permissions`.
- **`resume_work` & `wrap_up_work` Composite Workflows (`backend/` & `mobile/`):**
  - Implemented `_run_resume_work` in `backend/src/xuna_backend/modules/actions/application/workflows.py`:
    1. Wakes sleeping PC/Mac via `HostWakeRequestEvent` + `wait_for_host_online(20s)` if offline.
    2. Wakes display (`display.wake`, `R1`).
    3. Reads project Git summary (`workspace.git_summary`, `R1`) to resolve workspace name and branch status.
    4. Requests **one** `R2` approval (`"{host} · Mở {agent} ({workspace}) và tiếp tục công việc"`).
    5. Synthesizes continuation prompt from owner brief + live Git status and invokes `workspace.coding_agent` (`R2`).
  - Implemented `_run_wrap_up_work` in `workflows.py`: captures end-of-session `workspace.git_summary` (`R1`) and pauses active media (`media.play_pause`, `R1`).
  - Added `BoardWorkflowSlotConfig.devWorkspacePresets` (`resume_work`, `wrap_up_work`) in `mobile/`.
