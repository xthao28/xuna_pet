## Design freeze

- Production enables opcode 6, 12-byte packet, confirmed text source 2 only; capability byte 2 becomes 0x2f (bit 5), bits 4/6 remain off. GPIO0 remains direct Happy; day-part sync is S10-sync, not this slice. Coarse choice remains available offline; explicitly stated day-part evidence is stored but cannot drive fine-context choices until trusted sync.
- Explanation characteristic `7a6e000b-8c44-4db6-9f61-2b7d5300a101` is READ only; 0008–000a remain reserved for BLE v2. Available together with bit 5. Payload is existing ExplanationCodec V1, 20 bytes: version, size, interaction, day part, learner action index (0 idle/1 happy/2 curious), reason (0 invalid/1 highest/2 explore/3 no evidence/4 told), fine flag, saturated rated count, six LE u16 Q8.8 values (probability, effective mass, positive, negative, stated positive, stated negative). Empty explanation is valid version/size followed by zeroes, reason=0. Q8.8 masses are discounted evidence, not exact historical rating counts.
- Projection describes the last accepted app suggestion or confirmed statement in this boot/session, refreshed after feedback. Statement projection is evidence about the stated action, not a claim it was physically performed. Direct actions, disconnect/session reset and Forget clear the projection. A rejected command never replaces it.
- Dedicated result **8 = expired** on the enhanced path; baseline adapter defaults retain result 4 for S01 regression. Tick-expired and directly late feedback both return 8, while unknown/consumed/invalidated remains 4. App handles result 8 explicitly. No new capability bit is assigned.
- Mobile: immutable domain projection, strict model/codec, mapper, repository + read use case, optional read characteristic discovered only with bit 5. AskWhy in existing chat is the minimal UI. Confirmation replies read explanation; no claim of learning from a success code alone. Old firmware returns no explanation; no network or automatic retry.
- Simulator is a UI fake, not a second v3 learner. It returns no explanation rather than fabricating evidence. Tests use explicit firmware fixtures for grounding.
